## 项目简介

Atlas 面向 GPU 集群，并逐步扩展到服务器、存储和网络基础设施。它将分散的资产状态、监控信号、硬件问题和人工经验汇聚到统一工作台，帮助团队建立从发现、判断、处置到验证的可靠性闭环。

Atlas 正在持续迭代升级中。已上线能力会不断完善，处于早期阶段的能力也可能随版本演进。

## 产品原则

- 以真实资产和可追溯证据为基础；
- 明确区分硬件故障、数据质量问题和未知状态；
- 重要操作由人工确认，Atlas 不会擅自排空任务或隔离节点；
- 所有判断保留证据，所有处置形成可复用记录；
- 能力保持清晰、可解释、可验证，并持续迭代升级。

## 项目状态

Atlas 采用持续迭代的方式建设。当前重点是完善端到端的可靠性闭环，并持续增强数据质量、预测、验证和知识沉淀能力。本页的能力状态表示当前产品成熟度，不构成固定版本承诺。
