# ATLAS 平台能力模块与版本基线

> 产品名称：ATLAS — Infrastructure Hardware Reliability Workbench  
> 平台版本：v0.3.0  
> 能力基线日期：2026-07-20  
> 文档更新日期：2026-07-22

## 1. 正式产品介绍

ATLAS 是面向 GPU 集群并可扩展至服务器、存储和网络基础设施的硬件可靠性工作台，提供资产对账、监控数据质量发现、硬件健康评分、故障检测、硬件故障预警与预测、性能衰减识别、故障事件管理以及维修验证闭环。

当前实现以 GPU 为第一硬件对象。服务器、存储和网络硬件沿用相同的资产、数据质量、健康、事件、预测和维修验证模块扩展，不另建割裂的平台。

## 2. 模块版本规则

平台能力按模块独立采用语义版本 `MAJOR.MINOR.PATCH`：

- `MAJOR`：模块 API、状态语义、评分定义或数据契约发生不兼容变化
- `MINOR`：新增向后兼容的指标、规则、硬件类型、页面或工作流能力
- `PATCH`：规则阈值校准、缺陷修复、性能优化和展示修正
- `v0.0.0`：已完成路线设计，但尚未交付可运行模块
- `v0.x`：模块处于增量开发阶段，接口或状态语义仍可能调整
- `v1.x`：已经形成可运行、可验收和有版本契约的稳定基线

每次模块发布必须同步更新：模块版本、状态、功能范围、变更记录、数据/API 契约和验证结果。

平台页面默认仅展示各模块最近 3 次迭代，完整历史通过模块详情弹窗查看；本文件保留全部迭代记录，避免页面随版本增长失控。

## 5. 模块架构与关系

![ATLAS 平台模块架构](../web/public/atlas-platform-architecture.svg)

架构中的资产主数据以 [LXOPEasier](https://10.111.201.1:7090/) 为准；Prometheus/DCGM、系统日志和 BMC/IPMI 构成运行观测与故障详情。健康评分表达当前状态，故障检测确认已经发生或正在发生的问题，硬件故障预警与预测评估故障发生前风险，事件管理、AI + Skill 辅助和维修验证组成处置闭环。AI + Skill 当前为已确定实现路径，未进入开发。

## 6. 版本更新要求

模块发生功能变更时，应在同一次迭代中完成：

1. 更新本文件中的模块版本、状态和迭代历史。
2. 更新平台“能力与里程碑”页面。
3. 更新相关 API、数据模型、规则或算法版本。
4. 记录测试环境验证结果和已知限制。
5. 稳定运行并完成验收前，不将规划能力描述为已经交付。
